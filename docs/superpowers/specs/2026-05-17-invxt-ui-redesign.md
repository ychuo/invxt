# InvXt UI 系统性翻新 设计文档

> 日期：2026-05-17 | 状态：已确认

## 概述

对 InvXt 前端做系统性 UI 翻新，统一视觉语言，提升可读性和精致感。功能不变，纯视觉/交互优化。

## 设计系统

### 字体

- **全站统一 Georgia 衬线**：标题、正文、标签、分数、表头、按钮均用 Georgia
- **例外**：股票代码用等宽字体（monospace），功能性需求
- 中文字体回退：系统默认中文字体

### 色彩

- **主色调：青绿** — 渐变 #0d9488 → #14b8a6
- 背景：白色 #fff，页面底色 #f8f9fb
- 正文：深色 #0f172a / #475569，辅助文字 #94a3b8
- 功能色：
  - 高分/正面/完成：青绿系 #0d9488, #0f766e, #f0fdfa
  - 中分/警告：琥珀系 #d97706, #b45309, #fef3c7
  - 低分/灰：灰系 #cbd5e1, #64748b
  - A股标签：红 #dc2626, #fef2f2
  - 美股标签：蓝 #2563eb, #eff6ff
- 图谱节点色不变（Theme #e17055, Technology #74b9ff, Material #fdcb6e, Equipment #a29bfe, Company #00b894）

### 圆角与间距

- 大圆角：卡片/区块容器 10-12px
- 小圆角：按钮/标签 6-8px
- 全圆角：胶囊标签 100px
- 区块间距：24px
- 内容区最大宽度：880px

## 页面 1：首页 `/`

### 布局（保持左对齐，同现有结构）

1. **市场切换** — 灰色底胶囊按钮组，选中白底+青绿文字+微阴影
2. **品牌** — "InvXt"，X 用青绿渐变 #0d9488→#14b8a6，Georgia 44px 粗体
3. **副标题** — "产业链智能分析引擎 [图谱小标] 从模糊主题到结构化投资机会"，图谱小标是微型节点连线 SVG（3 节点+2 连线），青绿色调
4. **搜索框** — 白底+浅灰边框 1.5px，12px 圆角，内部输入 Georgia 斜体 placeholder，青绿渐变按钮"开始分析 →"
5. **快捷标签** — 下划线点缀式（border-bottom: 1px dotted），非胶囊框，Georgia 字体

### 去掉

- 底部技术栈注脚（DeepSeek · Neo4j · FastAPI）
- 原来的全大写文字描述

## 页面 2：分析结果 `/analysis?q=<topic>`

### 整体结构

长滚动单页 + sticky 顶部导航。

### Sticky 导航栏

```
[InvXt] | 搜索  图谱  公司  逻辑
         ———————（当前区块青绿下划线）
```

- 白色背景，底部 1px 灰线
- 左侧品牌名（渐变 X）
- 右侧区块快捷跳转链接，当前区块青绿高亮+下划线

### 页面标题区

- 主题名：Georgia 26px 粗体，深色
- 副行：市场标签 · [图谱小标] · 完成时间

### 进度条

- 5 个青绿圆点 ✓ 横向排列，中间用 `·` 分隔
- 全部完成后全部显示 ✓
- 进行中：当前步骤圆点 pulse 动画

### 区块 1：实时搜索

- 区块标题栏：`实时搜索` + 绿色"完成"徽章 + 结果数
- 内容：两列网格，每条结果：
  - 标题：Georgia 13px，青绿色 #0f766e
  - 摘要：Georgia 11px，灰色 #94a3b8
  - 域名：等宽 9px，浅灰
  - 整卡可点击，hover 边框加深
  - 卡片白底，1px 浅灰边框，8px 圆角

### 区块 2：主题理解

- 区块标题栏：`主题理解` + 绿色"完成"徽章
- 内容卡片（1px 边框，10px 圆角）：
  - 主题名：Georgia 18px 粗体
  - 摘要：14px 灰色，行高 1.7
  - 方向标签：淡青绿底+青绿边框胶囊

### 区块 3：产业链图谱

- **区块标题栏**（右置工具栏）：
  ```
  产业链图谱  [完成] 12 节点 · 15 连线     [公司] | [-] 100% [+] [复位] | [⛶]
  ```
  - 公司开关：激活时青绿底+青绿边框
  - 缩放/复位/全屏按钮：白底+灰边框，hover 变灰底
  - 分隔符：竖线

- **图例行**（标题栏下方，轻薄）：
  - 5 个色块标签 + 右侧"拖拽平移 · 滚轮缩放 · 点击节点"操作提示

- **图谱区域**：
  - 保持现有 Sankey SVG 渲染逻辑不变
  - 全屏时撑满视口，Esc 退出

- **节点弹窗**（新增）：点击公司/材料节点后，浮动卡片显示：
  - 公司名 + 暴露度分数 + 市场标签
  - 关联逻辑摘要
  - 关闭按钮

### 区块 4：核心公司映射

- 区块标题栏：`核心公司映射` + 绿色"8 家"徽章
- 增强表格：
  - 序号：Georgia 衬线，灰色
  - 公司名：Georgia 粗体深色，下方等宽灰色代码
  - 市场标签：A股红底、美股蓝底
  - 暴露度：大号衬线数字（青绿/琥珀/灰色按分数） + 横向进度条
  - 关联逻辑：12px 灰色，行高 1.5
  - 表头：全大写 9px 浅灰
  - 行 hover 浅灰底

### 区块 5：投资逻辑卡片

- 区块标题栏：`投资逻辑卡片` + 绿色"3 家"徽章 + "仅展示前三"
- 两列网格，每张卡片：
  - **卡片头部**（底部分割线）：
    - 公司名 Georgia 18px + 代码等宽小字
    - 市场标签 + 一句话定位
    - 暴露度大号数字（28px 衬线）+ 进度条
  - **卡片内容**（三部分）：
    - 投资逻辑 — Georgia 12px 正文，行高 1.7，完整 3-5 句
    - 关键变量 — 青绿色 `关键变量` 标签，每项：粗标题（青绿）+ 详细说明
    - 风险 — 琥珀色 `风险` 标签，每项：粗标题（琥珀）+ 详细说明

### 加载态

- **骨架屏**：表格/列表用灰色占位条替代空白 spinner
- **等待态**：未开始区块用虚线边框 + "等待上一步完成"说明文字
- **进行中**：区块标题栏显示琥珀色"进行中..."徽章
- **完成**：绿色"完成"徽章

## 验收标准

1. 全站字体统一为 Georgia（代码除外）
2. 青绿主色调贯穿所有页面和组件
3. 首页品牌展示：渐变 X + 图谱小标分隔符
4. 分析页 sticky 导航可跳转区块
5. 图谱工具栏单行右置，不再散落四角
6. 公司表格暴露度数字+进度条双通道
7. 逻辑卡片两列展示完整内容
8. 加载态用骨架屏，无空白 spinner
9. 暗色主题不做
